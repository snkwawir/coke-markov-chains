# Coca-Cola Stock Movement Forecasting Using Markov Chains

## Overview
This project develops discrete-time Markov chain forecasting models to analyze and predict stock movement behavior across multiple Coca-Cola-related equities using historical financial market data from 2002-2024. The analysis evaluates one-step and long-run transition probabilities, stationarity behavior, and directional forecasting accuracy across multiple international markets.

## Objectives
- Build stochastic forecasting models for equity price movement prediction
- Analyze transition probability behavior across multiple Coca-Cola-related equities
- Compare short-term and long-term stock movement probabilities
- Evaluate market stability and directional prediction performance
- Apply statistical validation and preprocessing workflows to historical financial datasets

## Tools & Technologies
- R
- QuantMod
- Markovchain
- dplyr
- ggplot2
- Time Series Analysis
- Statistical Modeling
- Financial Forecasting

## Key Features
- Built one-step and 30-step transition probability matrices
- Performed stationarity and volatility analysis across multiple equities
- Developed preprocessing and validation workflows for historical market data
- Compared forecasting behavior across domestic and international Coca-Cola-related stocks
- Evaluated long-run market movement probabilities using stochastic modeling techniques

## Results
The project demonstrated that Markov chain models could effectively capture directional market behavior above random baseline performance while providing insight into long-term market stability and transition dynamics across multiple financial assets.
